## Browser demo

Use a site you log into and are allowed to use. Dileep uses Every. Vishwas can use any paid subscription, X, or another login-only site.

1. Open the site in ChatGPT's browser (agent mode or Atlas) and confirm you are signed in.
2. Search the topic. Use filters if the site has them, otherwise check dates yourself.
3. Open up to two items and read them.
4. Record title, author, date and link, plus a short note.
5. Save a reading log and a brief.
6. On a repeat run, compare links with the log and skip what is done.

Rules:

- Read only. No posting, liking, following, messaging or buying.
- If a login, captcha or OTP appears, the agent pauses and you complete it.
- A preview is not the full article. Say so if that is all it could read.
- If a feed or a connector gives the same material, use that for a regular job.
- Check the site's terms on automated access. X restricts automation and scraping.

Fallback: a short recording of the run and the source list, labelled as prepared.

## ChatGPT writing style

OpenAI documents a writing-style setup in ChatGPT on the web ([guide](https://learn.chatgpt.com/docs/personalize)):

1. Open the writing-style setup.
2. Choose the connected apps that contain writing you authored.
3. Select "Use writing style".
4. Draft a short follow-up and check whether it sounds like you.

To change it later: Settings > Personalization > Writing.

Which plans include this control is not confirmed. A missing button does not prove an upgrade adds it. Record what your account shows during rehearsal. Claude has a separate Styles feature that learns from writing samples.

## Skills in ChatGPT

OpenAI's [Skills guide](https://learn.chatgpt.com/docs/build-skills) covers creating and uploading skills. Availability depends on plan, platform and workspace settings. Confirm that your account can save a skill and select it by name. If it cannot, paste the skill's instructions into the chat and call it manual use.
